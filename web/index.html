Each bit roughly doubles the work. ~18 is under a second; ~24 is a few seconds; ~28 is tens of seconds. The registry only ever raises your level, so aim above where you are.

Commit for an action what an app does

Behind the scenes, an app grinds against its own purpose string and has you sign a one-off proof for that specific action — it never shows you a hex string. This panel does it by hand so you can see the shape.
